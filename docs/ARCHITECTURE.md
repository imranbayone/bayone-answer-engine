## Why Each Component Was Chosen

**AWS Lightsail over EC2** — fixed monthly price, static IP included, simple firewall, browser-based SSH. No fine-grained control we actually need for a single-purpose box.

**Hermes over OpenClaw** — OpenClaw had a severe, ongoing vulnerability record (100+ disclosed CVEs, a 9.9-severity remote-code-execution flaw, a compromised skill marketplace, and a direct warning from Microsoft against running it on any standard machine). Hermes is MIT-licensed, runs in Docker sandboxing, keeps all data local with no telemetry, and has a learning loop that improves at repetitive tasks over time — which matches our daily scan/score/draft cycle well.

**Apify over the Reddit API** — Reddit's commercial API tier costs $12,000/month, which priced out third-party tools. Apify's actors scrape the public web instead, requiring no API key, no OAuth, and no developer account, using residential proxies to handle Reddit's rate limiting.

**Two Apify actors, not one** — `reddit-scraper-lite` covers the daily baseline (every post in our 30 subs). `reddit-scraper`'s keyword search catches high-intent phrases that might rank low in a subreddit's daily volume or slip past the broad scan's timing. Both write to the same downstream queue, tagged by source, which gives us a built-in comparison of which approach produces better-approved answers.

**OpenRouter over a single model provider** — model-agnostic access to 200+ models through one key, so we can route cheap/fast models for bulk scoring and a stronger model for the smaller number of actual drafts, and swap either at any time without rebuilding the pipeline.

**Google Sheets over Slack** — persistent, filterable, doubles as the KPI log for the weekly citation audit, and connects with a single service account rather than a Slack app review process.

**Human posting, always** — the agent never logs into Reddit and never posts. This is both a ban-risk decision and a brand integrity decision: the plan requires real, disclosed executives, not anonymous or automated accounts.

## Data Flow, Step by Step

1. Scheduled trigger fires (once daily in Sprint 1, moving to twice daily in Sprint 4)
2. Skill 1a and Skill 1b each call their Apify actor, results land in the agent's working memory
3. Skill 2's scoring pass runs a cheap OpenRouter model over every post, assigning a 0–100 relevance score against the rubric in `prompts/scoring_rubric.md`
4. Posts scoring 70+ get a full draft generated by a stronger OpenRouter model, using `prompts/drafting_prompt.md` and BayOne's content knowledge base for citable assets
5. Skill 3 appends one row per post to the correct portfolio tab in the Google Sheet, including score, service line, suggested owner, suggested executive, and the draft
6. The portfolio owner reviews their tab, edits or approves, and marks status
7. The assigned executive posts the approved answer manually and logs the resulting URL back into the sheet

## Security Posture

- Server firewall allows SSH only — no web-facing ports
- No third-party Hermes skills from any marketplace; only the four skills we write ourselves
- Server connects to GitHub via a read-only deploy key — it can pull updates, never push
- All API keys and the Google service-account JSON are configured directly on the server, never committed to this repo
- Regular Lightsail snapshots taken at sprint boundaries for rollback
- Monthly key rotation review (see `docs/SPRINT_PLAN_SUMMARY.md`, Sprint 4 ops hardening)
